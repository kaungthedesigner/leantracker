To install as a PWA on a phone:
1. Upload this whole folder to an HTTPS host (GitHub Pages, Netlify, Vercel, etc.).
2. Open the HTTPS site on your phone.
3. iPhone/Safari: Share -> Add to Home Screen.
4. Android/Chrome: browser menu -> Install app / Add to Home screen.

Progress can be manually added, edited, or deleted by date.
Data is stored locally in the browser on the device.
